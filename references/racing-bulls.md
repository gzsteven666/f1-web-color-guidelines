# 极速公牛车队风格的 HTML 设计指引（Visa Cash App RB / 2026 VCARB 03）

## 设计目标

做出 **充满意式赛车激情、高闪耀电镀宝蓝光泽、极速纯白条带与明亮科技活力** 的 F1 官方级现代网页视觉，彻底摆脱沉闷的灰暗后台感，同时与一队（Red Bull Racing）的哑光暗夜蓝形成截然不同的两极风格。

整体严格遵循 Visa Cash App RB Formula One Team 针对 2026 规则赛车 **VCARB 03**（意大利法恩莎研发设计）的官方设计语汇：**极高光泽电镀金属皇家宝蓝（Electric Candy Royal Blue）作为车身绝对核心，大面积横贯侧箱的空气动力学纯白条纹（Aero Silver-White Band）形成鲜明视觉节奏，公牛活力红（Toros Dynamic Red）提供速度爆点，底盘暗夜碳黑（Chassis Nero Black）牢固支撑机械质感**。

VCARB 是 F1 围场中最具年轻活力与数字化科技跨界属性的车队。网页转译时必须保持这四者的结构秩序：**电光宝蓝是高调主色，纯白条带是速度切割，公牛红是热情点睛，底盘暗黑是机械骨架**。

## 二、网页配色占比与面积法则

VCARB 的视觉特征在于 **“高光泽电光宝蓝与大面积纯白条纹的鲜明对冲，配以极小比例的公牛火红”**。

### 1) 推荐整页占比（沉浸式 Surface 展示页）

* **暗夜底盘与碳黑深蓝（#070B14 / #0C162A）**：约 **58%**（保证暗夜界面的沉浸感）
* **电镀宝蓝主车漆（#1640D6 / #4A7BFF）**：约 **26%**（耀眼主视觉）
* **极速纯白与高对比文字（#FFFFFF）**：约 **13%**（构筑速度条纹与文字留白）
* **公牛活力红（#E51937）**：**严格控制在 3% 以内**（仅作为脉冲笔尖与主 CTA 点睛）

### 2) 绝对禁止项（Anti-patterns）

* ❌ **禁止与红牛一队的哑光 Navy 混淆**：VCARB 绝对不是哑光！它有着全围场最明亮的镜面高光清漆（High-Gloss Candy Coat），高光反差极其锐利。
* ❌ **禁止忽视白色条纹的存在**：如果全页只有蓝和红，就失去了 VCARB 标志性的极速拉花律动。白色条纹必须作为卡片切角或分割装饰穿插其中。
* ❌ **禁止使用陈旧沉闷的灰蓝色**：宝蓝必须是充满电气活力的 `#1640D6`，绝不能暗沉为商务海军蓝。

## 三、元素级组件设计规范

### 1) 背景与连续车身

* `body` 底色统一锚定 `#070B14`，背景使用 PBR 电镀金属宝蓝车身 Shader。
* WebGL 回退方案使用双层方向性高光受光渐变：
  ```css
  background:
    radial-gradient(110% 68% at 22% 10%, rgba(74, 123, 255, 0.42) 0%, transparent 60%),
    linear-gradient(155deg, #1034B0 0%, #0A1C4D 38%, #070B14 100%);
  ```

### 2) 按钮与行动点（CTA）

* **主按钮（Velocity White）**：
  * 背景：`#FFFFFF`
  * 文字：`#070B14`（极具力量感的高对比黑字，粗体大写）
  * 悬浮态：背景变为电光宝蓝 `#1640D6`，文字变为 `#FFFFFF`，`box-shadow: 0 0 20px rgba(22, 64, 214, 0.5)`
* **次级按钮（Toros Red Accent）**：
  * 背景：`rgba(229, 25, 55, 0.10)`
  * 边框：`1px solid rgba(229, 25, 55, 0.40)`
  * 文字：`#E51937`
  * 悬浮态：`background: #E51937`, `color: #FFFFFF`

### 3) 赛道贯穿线（Track Keyline）

* 颜色：`#FFFFFF`（纯白速度主线）
* 笔尖发光点：`#E51937`（公牛火红动能点）
* 线宽：`2.5px`，带有清晰锐利的速度感。
