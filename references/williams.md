# 威廉姆斯车队风格的 HTML 设计指引（Atlassian Williams F1 Team / 2026 FW48）

## 设计目标

做出 **坚定、明亮、纯粹且带有英国顶级工程传承与夺冠底蕴** 的网页视觉，彻底摆脱泛泛无奇的“企业蓝 SaaS 后台”或“普通科技蓝模板”。

整体严格遵循 Atlassian Williams F1 Team 针对 2026 规则赛车 **FW48** 的官方设计语汇：**高光泽鲜蓝（Vibrant Gloss Blue）作为绝对主识别与车头曲面，从车身侧壁流向尾部的空气动力学流动黑色（Flowing Carbon Black）压稳机械重心，前翼、侧箱切口与端板的大面积结构白（Structural Wing White）形成极高对比的几何分区，以及在蓝黑相接的轮廓线上、仅有一笔极细的红白双色历史冠军描边（Championship Heritage Keyline）**。

2026 年是威廉姆斯迈向新时代的工程纪元，设计语言连接了 Frank Williams 爵士经典的“Forward W”向前动量与牛津郡格罗夫（Grove HQ）的尖端复合材料科技。网页转译时必须保持这四者的结构秩序：**蓝色是身份，黑色是机械骨架，白色是结构切面，红色是不可多得的历史勋印**。

## 一、核心配色方案

### 1) 品牌核心层（2026 网页复现基准值）

这层负责让界面在 0.1 秒内展现 Williams Racing 的纯正血统：

* **FW48 鲜蓝主漆 / Vibrant Gloss Blue**：`#0858C9`
  * 赛车鼻锥、前车身、主行动点（CTA）与首屏曲面光影的主识别色。非荧光电竞蓝，而是具备高饱和度、高光泽清漆包裹下的英式赛车蓝。
* **车漆受光蓝 / Blue Highlight**：`#4089E5`
  * 3D 曲面朝向摄影棚主光源时的反射亮带，以及交互激活高光。
* **深海夜蓝底 / Deep Abyss Blue**：`#050B14`
  * 页面的终极底色，比纯黑更深邃、带有冷蓝色调的太空暗部。
* **流动车体碳黑 / Flowing Chassis Black**：`#0A1220`
  * 侧箱下洗区、扩散器与后半部结构收束色，承载机械体积感。
* **结构羽白 / Wing White**：`#F4F7FA`
  * 2026 FW48 涂装突破性的空气动力学切面白，用于前翼端板、重要数据切面与顶级标题。
* **历史冠军红 / Championship Heritage Red**：`#D6293E`
  * 致敬车队 9 座车队总冠军的传统血统红。**极度克制**，仅作为细描边与关键指标端点，严禁大面积铺底。

### 2) 推荐可替代与扩展色阶

如果你需要构建复杂的数据可视化、性能监控仪表盘或工程参数面板，使用同一世界观内的专业级衍生色阶：

* **浅天蓝高光 / Aero Specular**：`#7CB2F1`（仅用于微光折射、次级遥测波形）
* **深邃主蓝 / Chassis Cobalt**：`#06449D`（按钮 Hover、浅底模式标题）
* **二级面板黑 / Cockpit Navy**：`#101D31`（一级卡片背景）
* **三级悬浮黑 / Telemetry Slate**：`#182942`（悬浮菜单、下拉面板）
* **冷合金边框 / Composite Hairline**：`#253852`（1px 精密结构线）
* **高对比白描边 / Pure White Keyline**：`#FFFFFF`（与 Heritage Red 构成双轨细线）

### 3) 页面结构层（暗色基准）

* **主画布背景**：`#050B14`
* **一级容器底色**：`#0A1220`
* **二级卡片底色**：`#101D31`
* **交互与弹出层**：`#182942`
* **微细边框 / 导轨**：`#253852`（或 `rgba(244, 247, 250, 0.12)`）
* **强化边框**：`rgba(64, 137, 229, 0.40)`
* **主阅读文字**：`#F4F7FA`（Contrast Ratio > 14:1）
* **次级工程文字**：`#C3D0E1`
* **弱化注记 / 遥测标签**：`#8A9EB8`

### 4) 数据可视化与遥测层

威廉姆斯仪表系统采用 **鲜蓝主系列 + 结构白参考线 + 极少红点标定** 的严谨工程秩序：

* **Series 1（主遥测轨迹）**：`#4089E5`（受光鲜蓝）
* **Series 2（对比基准曲线）**：`#7CB2F1`（浅天蓝）
* **Series 3（风洞目标线）**：`#F4F7FA`（纯白结构）
* **Neutral / 辅助网格**：`#253852`
* **Status Optimal（正常）**：`#4089E5`
* **Status Warning（注意）**：`#E5B842`
* **Status Critical / Pit Limit（临界）**：`#D6293E`（仅此一处用红）

## 二、网页配色占比与面积法则

页面绝不能被做成“全屏大蓝底”或“蓝红杂糅的运动饮料罐”。威廉姆斯的视觉重心在于 **深邃沉稳的暗夜底盘支撑着一块掠过的鲜亮蓝漆，由洁净利落的白色切面拉开呼吸感**。

### 1) 推荐整页占比（沉浸式 Surface 展示页）

* **深海夜蓝与底盘碳黑体系（#050B14 / #0A1220）**：约 **52%**（筑牢机械稳定度）
* **FW48 鲜蓝主漆识别区（#0858C9 / #4089E5）**：约 **22%**（车漆主视觉与高光）
* **结构白与高对比文字（#F4F7FA / #FFFFFF）**：约 **18%**（切面留白与可读性）
* **金属冷灰与工程分割线（#253852 / #C3D0E1）**：约 **7%**
* **冠军历史红（#D6293E）**：**严格限制在 1% 以内**（仅作为双轨描边与临界指示）

### 2) 仪表盘与监控后台（Dashboard 模式）

* **暗夜深蓝底板**：约 **68%**
* **结构白数值与标签**：约 **16%**
* **鲜蓝主图表与 CTA 控件**：约 **12%**
* **冷天蓝交互悬停**：约 **3%**
* **历史红状态灯**：**< 1%**

### 3) 绝对禁止项（Anti-patterns）

* ❌ **禁止大面积铺红**：红色不是第二主色！如果把主按钮或顶部横幅做成红色，整页瞬间沦为“百事可乐”或“运动饮料”。
* ❌ **禁止泛滥的赛博霓虹外发光**：FW48 是真车高光泽烤漆（High Gloss Paint），反射来自顶部柔光灯箱，绝非廉价发光阴影（`box-shadow: 0 0 30px blue`）。
* ❌ **禁止平淡的居中圆角卡片**：避免超过 8px 的大圆角，采用 2~4px 的硬朗微切面或直角，传递英国 Grove 工厂的一级方程式精密公差。
* ❌ **禁止仿制官方 Logo**：通过纯粹的色彩秩序与 Forward W 的向前斜线韵律传递气质，不随意粘贴非授权矢量标。

## 三、元素级组件设计规范

### 1) 背景与连续车身

* `body` 底色统一锚定 `#050B14`，固定背景使用 PBR 连续车漆 Shader。
* WebGL 回退方案使用双层真实物理受光渐变：
  ```css
  background:
    radial-gradient(110% 70% at 24% 10%, rgba(64, 137, 229, 0.35) 0%, transparent 58%),
    linear-gradient(142deg, #0858C9 0%, #06449D 38%, #0A1220 72%, #050B14 100%);
  ```

### 2) 导航栏（Cockpit Telemetry Nav）

* 背景：`rgba(5, 11, 20, 0.88)` 结合 `backdrop-filter: blur(16px)`。
* 边框：底部 `1px solid rgba(244, 247, 250, 0.12)`。
* 字体：工程等宽 `IBM Plex Mono` 12px 大写标签，主标采用 `Archivo` 700。
* 激活指示：`#4089E5` 配合底部 2px 结构线。

### 3) 交互按钮

* **主按钮（Vibrant Blue Primary）**：
  * 背景：`#0858C9`，文字：`#FFFFFF`，边框：`1px solid rgba(255, 255, 255, 0.2)`，圆角：`2px`。
  * Hover 态：背景升至 `#06449D`，外发光约束在单向柔光 `box-shadow: 0 4px 16px rgba(8, 88, 201, 0.45)`。
* **次级按钮（Cockpit Outline）**：
  * 背景：`rgba(10, 18, 32, 0.65)`，边框：`1px solid #253852`，文字：`#F4F7FA`。
  * Hover 态：边框亮起为 `#4089E5`。

### 4) 双轨冠军历史描边（Championship Keyline）

只在蓝黑交接或重磅板块上方出现一次，采用经典红白并列细线：

```css
.williams-keyline {
  position: relative;
  height: 2px;
  background: #FFFFFF; /* 上层：纯白结构线 */
  box-shadow: 0 2px 0 0 #D6293E; /* 下层：冠军历史红 */
  margin: 48px 0;
  width: min(480px, 100%);
}
```

## 四、浅色编辑模式规范（Editorial Mode）

当面向技术特刊、白皮书或历史回顾杂志式排版时，启用浅色编辑模式：

* **纸张底色（Paper Base）**：`#F4F7FA`（源自 FW48 结构白）
* **微光背景（Mist）**：`#E8EEF5`
* **深墨正文（Deep Ink）**：`#050B14`
* **主识别蓝（Editorial Blue）**：`#0858C9`
* **深蓝标题（Deep Cobalt）**：`#06449D`
* **版面布局**：大跨度衬线标题（`Source Serif 4`）与等宽工程参数（`IBM Plex Mono`）碰撞；穿插 100% 宽度的深海夜蓝与鲜蓝车漆切片，形成如同在牛津郡研发中心翻阅机密技术档案的克制权威感。
